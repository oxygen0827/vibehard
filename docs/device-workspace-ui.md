# AI 调试与嵌入式开发：简洁工作界面

2026-10-01，本地实现与测试完成；用户已授权上线，正在执行 Git/CI 与独立候选发布门槛。

## 任务边界与设计

用户要求在原先简洁清晰的 UI/UX 上补功能，而不是把两页直接变成三栏 Agent 项目工作台。允许修改共用工作台的模块呈现、USB 组件的展示方式、使用说明、行为测试与交接文档；不修改认证/归属、数据库、API、审批规则、Runner/Gateway、设备执行或已验证硬件代码。主工作区和另一个开发结果归档工作树不动。

- 顶部项目下拉和跨模块链接保留同一项目；设备条独立展示，报告状态不等于实时设备身份。当前免安装 USB 只读体检只支持 RV1126B，并不限定项目板型。
- 原来的卡片/双栏视觉恢复：左侧调试目标/开发需求，右侧实际日志与结果；窄屏上下排列。
- 资料/历史结果与会话/模型默认折叠，审批不折叠、不隐藏。工程 ZIP/资料入口仍属于当前项目。
- 准备清单或计划只预填简短任务并打开会话，不请求模型；明确点击“发送任务”可建立缺失会话并提交一次请求，后续沿用现有会话。服务端权限/模型/资料归档链保持。
- 内部工作流提示在提交时附加，仍要求实际读本项目文件、标出缺项，不猜引脚或宣称模拟调通。失败显示服务端错误、保留输入，不自动重试。
- 两种展示共用事件内容、来源证据、推理折叠、固定滚动区和审批卡片，不引入另一套 Agent 或模拟执行。Agent 项目本身继续作为归档与工程会话中心，不出现 USB 连接控件。

## 本地证据

455 常规测试通过，30 项环境条件用例跳过；28 项工作台/设备/滚动区定向测试通过，TypeScript、定向 ESLint、`/vibehard` Next 生产构建通过。新增 7 项行为覆盖双模块默认简洁布局、首次显式提交与会话复用、错误保留需求、建会话失败不发模型请求、历史输出/审批不被折叠隐藏。项目切换、无权项目不兜底、设备报告真实归档组件既有回归继续通过。

浏览器在仅回环的合成预览验证 1280×720、390×844、320×568；无横向溢出。100 条合成工具日志时，手机结果面板仍为 520 px、消息可滚动内容大于 22,000 px；推理默认折叠。预览明确标为合成数据，没有登录生产、读取 Cookie/密码、调用真实模型或连接 USB，不把界面测试当成设备执行或持久化端到端验收。

本轮没有生产变更或发布。线上仍为 `20261001-project-archive-ui-v4`；独立的新开发结果关联/0010 依然未发布。后续发布需基于最新默认分支评审/CI，并重新准备精确运行时文件清单和候选验证：上一轮仅两文件的 UI 发布脚本不能直接用于此版。
