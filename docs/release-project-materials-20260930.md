## 用户入口及限制

- 新生成方案的结果页显示“资料配套检查”；方案记录和 Agent 项目概览可下载“项目资料包 ZIP”。
- 包含需求、方案、BOM、检查报告、最多 5 条来源摘录和带哈希的清单；不是全部芯片资料原件。Agent 的既有 `designs/` 文件同步会携带报告。
- AI 调试、嵌入式开发、Agent 项目共用同一项目选择、资料、会话、审批和产物。点击准备按钮只填入计划，用户发送才请求模型。
- 检查只覆盖本次受控检索证据，未命中标为“本次证据未覆盖”；保守匹配不保证每颗器件都有对应资料。候选样本出现未覆盖/型号不明确，未伪造“资料齐全”。来源未人工复核不等于电气/板型正确。
- 历史方案保持旧文件和哈希，不自动补造配套报告；旧方案下载包会说明未记录。完整原件复制、逐器件补检索、云端到 USB 设备的跨 Runner 执行仍属后续阶段。
