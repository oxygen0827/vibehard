# 云端 LLM 配置与验收

## 已上线能力

入口：[管理概览](https://ldcx.tech/vibehard/app/admin) → LLM 服务设置，仅管理员可读写。

| 用途 | 调用路径 | 协议要求 |
| --- | --- | --- |
| 硬件方案生成 | 浏览器 → 平台 `/api/design` → LLM | Chat Completions 或 Responses；能返回有效结构化 JSON |
| Agent 对话与执行 | 浏览器 → 平台/Gateway → cloud-runner → Codex → LLM | Responses、流式输出及 Codex 工具调用兼容 |

两项可用不同模型、地址和 Key，不依赖知识库。方案页不再使用固定 ESP32 BOM、模拟等待或假 ERC 通过；模型失败只显示错误。输出为待核验建议，不是已验证电路。

## 操作

1. 使用管理员账号登录；普通成员不能修改全站模型配置。
2. 填服务商 API Base URL（通常包含 `/v1`，不要填写 `/responses` 等完整端点）、实际模型 ID 和 API Key。
3. 点击“测试连接”。测试使用小请求并核对随机标记，会消耗少量额度，**不会保存配置，也不代表完整 Agent 工具链验收**。
4. 点击“保存配置”。已有 Key 留空会保留；换服务地址必须重新输入 Key，避免旧 Key 被发送到新地址。
5. 已打开的 Agent 工作台刷新模型列表，再发新任务。运行中的任务继续使用启动时配置，不强制中断。

保存设置无需 SSH、重启平台或重启 Runner。云端 Runner 按任务读取最新配置；设备 Runner 不接收这份云端密钥。Agent 不是“任意聊天模型即可替换”，需满足上表协议。

## 安全与运维

- API Key 用 AES-256-GCM 加密落库，管理页 GET 不返回原文；不写入 Git、命令参数、任务事件或审计正文。
- 加密密钥使用 `LLM_SETTINGS_SECRET`，未设置时派生自 `SESSION_SECRET`。备份数据库必须同时妥善备份对应密钥；直接更换会导致旧配置无法解密，应先制定密钥迁移方案。
- 配置接口有角色校验；保存有版本冲突检查。调用限制超时、响应体大小和请求频率；拒绝私网目标及重定向并固定 DNS 解析结果。
- 仅已认证、持有对应活跃任务的 `cloud-runner` 可获取运行时凭据。更换 Runner 身份需独立受控操作，不随模型保存轮换凭据。
- 方案接口每 10 秒发送等待心跳，可取消；Agent 有有限重试和 120 秒空闲保护，审批等待不计入空闲。它们降低悬挂风险，无法保证上游服务可用。
