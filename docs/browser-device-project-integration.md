## 使用与发布边界

Agent 项目 / AI 调试 / 嵌入式开发 → 选择当前项目 → 项目概览内“USB 设备 · RV1126B” → USB 连接并归档只读报告 → 项目资料下载/查看 → “让 Agent 分析这份设备报告”预填任务 → 手动发送。模型使用云端 Runner，本机只通过浏览器读取 USB，不需要本机 Agent。浏览器需桌面 Chrome/Edge、HTTPS/localhost、板子已有可访问 ADB 接口；被本机 ADB 独占、需 RSA 授权等情况明确报错，不自动停止软件或安装密钥。

发布只切平台、云端 Runner 与新载荷必需 Gateway，保留 Worker/检索/EDA/VibeBoard/nginx、凭据、OSS和原索引。候选、备份、零活跃任务与保护页检查通过才激活。无生产数据库迁移。旧版本不识别新报告 JSON，归档开始后不得盲目回退旧解析器；回滚脚本仅在新报告数为零时恢复旧 unit，已有真实用户报告时保留兼容后端并前向修复，不自动删报告或恢复整库。
