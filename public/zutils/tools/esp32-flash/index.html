连接不上？查看常见解决方法
  1. 确认使用的是支持数据传输的 USB 线，非仅充电线。
  2. 安装对应芯片的驱动：CH340/CH341 使用 CH341SER，CP2102 使用 CP210x。
  3. ESP32-S3/C3 原生 USB 口可使用自动复位或 USB-JTAG 复位。
  4. 外置 UART 芯片可按住 BOOT/FLASH，短按 RST/EN，松开 BOOT 后再连接。
  5. 关闭 Arduino IDE 串口监视器等占用串口的程序后重试。
