什么是 JSON?

JSON (JavaScript Object Notation) 是一种轻量级的数据交换格式，易于人阅读和编写。

功能特性

支持格式化美化、压缩、键名排序、转义/反转义等多种操作。

隐私与安全

所有操作都在浏览器本地完成，数据不会上传到服务器，确保敏感信息安全。
